# 五子棋网页版

纯前端五子棋棋盘游戏，可直接在浏览器中运行。当前支持本地双人对战，后续计划加入联网对战和 AI 对手。

## 功能特性

- **自由棋盘尺寸** — 支持 5×5 到 50×50 任意尺寸
- **本地双人对战** — 黑白双方在同一设备上轮流落子
- **胜负判定** — 四个方向检测（横、竖、两条对角线）
- **对局历史** — 记录每局获胜方及回合数
- **零依赖** — 纯 HTML、CSS、原生 JavaScript，打开即玩

## 快速开始

### 对于frontend v1.0.0

下载压缩包并解压，用任意现代浏览器打开 `1.0.0.html` 即可。无需构建、无需服务器。

### 对于frontend v1.1.0 至 frontend v1.4.1

下载压缩包并解压，用任意现代浏览器打开 `main.html` 即可。无需构建、无需服务器。

### 对于frontend v1.4.3及以后的版本

下载时选择frontend-offline并解压，用任意现代浏览器打开 `游戏入口.html` 即可。

如果用于服务器部署，下载时选择frontend。

```
游戏资源/
├── main.html      # 主页面
├── JScode.js      # 游戏逻辑
├── black.png      # 黑子图片
├── white.png      # 白子图片
└── README.md
```

## 玩法说明

1. 输入棋盘宽度和高度（如 15 × 15）。
2. 点击**开始**生成棋盘。
3. 黑方先行，点击空格上的**落子**下棋。
4. 率先在横、竖或斜方向连成 5 子的一方获胜。
5. 点击**对局历史**查看过往战绩。
